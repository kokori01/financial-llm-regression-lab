Only these reviewed reports are included in Git. The original full live Markdown/JSON, private request journal, access checks, authorization and planning records, analysis scratch files and older operational reports remain local and ignored. The public extract omits provider response IDs and operational records without changing response strings, scores, token counts or latency.

The extract was generated by [export_public_report.py](../scripts/export_public_report.py) from the privately retained originals. Those original inputs are intentionally not part of a public checkout. Verification requires only public files: run `python scripts/verify_public_report.py` after installation to reconstruct inputs, check source hashes, rescore all saved outputs and recalculate estimated costs. It makes no API calls.

The JSON includes a SHA-256 identifying the original source report and lists omitted fields. It is an author-recorded experiment, not a provider-signed attestation. See [interpretation](../docs/LIVE_RESULTS_20261109.md).
